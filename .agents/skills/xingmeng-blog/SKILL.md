# 星梦启航博客

这是使用 VitePress 和 Vue 的个人博客，发布到 GitHub Pages。在本仓库执行任务前阅读此入口，再按任务读取相关参考文件；实现事实仍以当前源码为准。

## 约定

- 严格遵守仓库根目录 `AGENTS.md` 的会员内容访问规则；不得通过构建、数据加载器或线上副本间接处理会员正文。
- 优先修改现有组件和工具，不为小功能引入新的状态管理、服务层或依赖。
- 页面设计与交互以用户已经确认的行为为准；发现待办不等于获得实现待办的授权。
- 完成一段有结论的工作后，仅将新增的已确认决策、实现、踩坑或待办更新到对应参考文件。待办记录已确认的问题；猜测和未确定方案标为“待定”，不写成事实。原位修订已有条目，不连续追加过程日志。
- 不记录大段代码、密钥、激活码、私人数据或会员正文。无新增知识时不为留下记录而修改 Skill。
- 文档自动维护不代表获得 commit、push 或发布授权；完成后在回复中用一句话说明记录了什么。

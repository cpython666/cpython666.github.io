# 提示词与分享

## 来源与展示约定

- 唯一内容来源为 `docs/navigation/NavIndex.vue` 的 `prompts` 数据；本文件记录用途与行为，不另存一份长提示词正文。
- 提示词位于 `/navigation/` 的“提示词” Tab，与“文章” Tab 分开。
- 提示词采用随屏幕宽度排列为 3 / 2 / 1 列的等高摘要卡片；正文仅以 CSS 截为四行，底层原文不截断，复制仍获取完整文本。
- 标题旁放带可访问名称的复制、分享图标按钮；卡片底部是“查看完整内容”，不要恢复底部复制按钮或“复制后即可使用”提示。
- “查看完整内容”打开原生 `dialog`，全文在弹窗内滚动，弹窗提供复制全文和分享操作；关闭按钮、Escape 或遮罩可关闭，并恢复到打开前的焦点。
- 复制成功/失败以短暂弹出提示反馈，当前自动关闭时间为 3 秒；卸载时清理计时器。
- 网页对话版封面提示词 `video-cover` 保留 `{{视频标题}}` 变量及原文，视频标题输入框位于全文弹窗内；输入值替换模板后用于卡片摘要、全文展示和复制，未填写则保留变量标记。
- Codex 版封面提示词 `video-cover-codex` 按用户给定原文保留具体视频标题、16:9 / 4:3 / 3:4 三种比例及末尾视频文案参考引导；不将具体标题改成变量，也不受网页对话版输入影响。两版分别维护，旧 ID 不变。
- 术语字幕修复与文案参考字幕修复是两条独立提示词，保留旧条目，不能用新版覆盖旧原文。
- 修改提示词时保持用户确认的原文，除非本次明确要求改写；分享链接不能把长提示词全文当作 URL 标识。

## 分享协议

- 卡片及弹窗内的分享复制两行文本：第一行为提示词标题，第二行为固定域名和稳定 ID 构成的链接 `https://cpython666.github.io/navigation/#prompt-<id>`，两行之间使用换行符。
- 分享不包含用户填写的视频标题或其他输入。新增提示词分配唯一的稳定 ID，改标题或排序时不要改已有 ID，以免旧链接失效。
- 页面初始化、SPA 导航和 hash 变化时识别有效 ID，打开“提示词” Tab，再滚动、聚焦并高亮对应卡片，不自动打开全文弹窗；旧分享链接继续有效，未知 hash 默认回到“文章” Tab。
- 手动切换到提示词使用 `#prompts`，切到文章清除 hash；通过 `replaceState` 保留当前 query，避免仅切 Tab 就增加历史记录。

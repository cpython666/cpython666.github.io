# 提示词与分享

## 来源与展示约定

- 唯一内容来源为 `docs/prompts/prompts.js` 的 `prompts` 数据，`PromptPage.vue` 引入展示；本文件记录用途与行为，不另存一份长提示词正文。
- 提示词是独立的 `/prompts/` 页面；`/navigation/` 只展示文章目录，不再使用文章/提示词 Tab。两页顶部直接进入搜索、分类和内容，不显示重复的大页面标题、介绍及统计卡片；保留隐藏的 h1 供辅助技术识别页面。
- 顶部“提示词”入口直达 `/prompts/`。每条数据含 `id`、`title`、`category`、`text`；分类按钮由数据生成，搜索覆盖标题、正文和分类，可组合筛选、显示匹配数量，并在空结果时重置。
- 分类栏滚动时吸附并保持单行：960px 及以上贴在固定站点顶栏下方，959px 及以下贴视口顶部（该宽度的站点顶栏随页面滚走）；窄屏在分类栏内横向滑动，不把页面撑宽或占用多行高度。切换分类后滚动到首张匹配卡片，避免沿用长列表原位置而只看见分类末尾；分享定位和分类切换均预留顶栏与分类栏高度，标题不被遮挡。
- 当前共 26 条：保留原 8 条及 11 条脱敏模板，另补充 6 条骑行 SVG 原始提问和 1 条“按功能分批提交并推送（中文说明）”。按视频创作、图像与设计、编程与项目、信息检索、效率与排障、学习与阅读、模型测试共 7 类组织；分类顺序取数据中的首次出现顺序，同类模板放在一起。用户已从原 40 条清单中删除第 7、10–27、33、34 条：录屏双路收音、3D建模/游戏设计/界面与体验三类全部条目，以及逐关路线验收、动作打断状态机；保留条目的 ID、原文与相对顺序不变。
- 新增模板按用户要求从本地 ChatGPT / Claude 导出的用户提问中提炼，合并重复请求、跳过无上下文确认和敏感私人话题，不把助手回答或系统上下文当作用户提问。姓名、账号、真实路径、会话链接、内部项目与角色信息替换成【占位符】；原始对话、附件、来源映射与本地归档路径不写入网站或仓库。模板是脱敏整理，不宣称逐字转录。
- 提示词采用随屏幕宽度排列为 3 / 2 / 1 列的等高摘要卡片；正文仅以 CSS 截为四行，底层原文不截断，复制仍获取完整文本。
- 标题旁放带可访问名称的复制、分享图标按钮；卡片底部是“查看完整内容”，有 SVG 成品时为“查看提示词与作品”；不要恢复底部复制按钮或“复制后即可使用”提示。
- “查看完整内容”打开原生 `dialog`，全文在弹窗内滚动，弹窗提供复制全文和分享操作；关闭按钮、Escape 或遮罩可关闭，并恢复到打开前的焦点。
- 8 条骑行提示词通过 `preview` 引用 `docs/public/prompt-examples/` 的原有 SVG 成品，全文弹窗用 img 展示并提供下载；不把 SVG 内联到页面，不改原图、不发布原始本地路径。鹈鹕、小姑娘是静态 SVG，其余六份有动画，统一称“SVG 作品”。
- `previewStatus` 与 `previewNote` 记录作品标签和蹬车检查依据，卡片、弹窗均显示。用户确认按“能正常蹬车”判断：佩奇、熊大、二郎神、哪吒为“正常”；鹈鹕、小姑娘、光头强、图图为“降智”。判定针对这份成品：前两份没有动画，光头强脚未沿踏板闭环，图图双腿固定；不得据此改写为模型整体能力结论。没有足够依据时标“待标注”。
- 复制成功/失败以短暂弹出提示反馈，当前自动关闭时间为 3 秒；卸载时清理计时器。
- 网页对话版封面提示词 `video-cover` 保留 `{{视频标题}}` 变量及原文，视频标题输入框位于全文弹窗内；输入值替换模板后用于卡片摘要、全文展示和复制，未填写则保留变量标记。
- Codex 版封面提示词 `video-cover-codex` 按用户给定原文保留具体视频标题、16:9 / 4:3 / 3:4 三种比例及末尾视频文案参考引导；不将具体标题改成变量，也不受网页对话版输入影响。两版分别维护，旧 ID 不变。
- 术语字幕修复与文案参考字幕修复是两条独立提示词，保留旧条目，不能用新版覆盖旧原文。
- 修改提示词时保持用户确认的原文，除非本次明确要求改写；分享链接不能把长提示词全文当作 URL 标识。

## 分享协议

- 卡片及弹窗内的分享复制两行文本：第一行为提示词标题，第二行为固定域名和稳定 ID 构成的链接 `https://cpython666.github.io/prompts/#prompt-<id>`，两行之间使用换行符。
- 分享不包含用户填写的视频标题或其他输入。新增提示词分配唯一的稳定 ID，改标题或排序时不要改已有 ID，以免旧链接失效。
- 页面初始化、SPA 导航和 hash 变化时识别有效 ID，滚动、聚焦并高亮对应卡片，不自动打开全文弹窗；未知 ID 不高亮、不打开弹窗，页面仍可浏览提示词。
- 有效分享链接会清空分类和搜索，确保目标可见；手动筛选时清除旧定位 hash，避免再次打开同一分享链接时不触发定位。
- 旧 `/navigation/#prompts` 通过 `location.replace` 转到 `/prompts/`，旧 `/navigation/#prompt-<id>` 转到 `/prompts/#prompt-<id>`；保留 query，替换中间历史记录，兼容已有分享。`NavIndex.vue` 只保留这一小段兼容跳转，不再引入提示词组件或数据。手动筛选通过 `replaceState` 保留 query、清除定位 hash，不增加历史记录。

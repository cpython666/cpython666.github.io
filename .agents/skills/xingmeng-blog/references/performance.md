# 性能约定

以下是已确认存在的实现语义，修改时避免退回原有持续空转或阻塞页面的行为；不代表线上性能指标已经量化。

## 全局脚本

- `docs/.vitepress/config.mjs` 给现有 6 个外部 head 脚本添加 `defer`；保持 `anime.min.js` 在 `fireworks.js` 之前执行，不能随意改成不保证顺序的 `async`。
- 飞鸟、鼠标轨迹与烟花保留原效果和开关；设置仍使用 `cpython666:disable-*` 键及 `cpython666-effects-change` 事件，不在每帧轮询存储。
- 三种效果响应设置变化、跨页签存储变化、页面可见性和 `prefers-reduced-motion` 变化。隐藏页面或要求减少动态效果时清理，恢复时按设置重新初始化，不能重复创建画布或飞鸟。

## 各效果生命周期

| 实现 | 应保持的行为 |
| --- | --- |
| `docs/public/js/mouse-trail.js` | 鼠标移动才请求动画帧；轨迹消退后停绘；resize 时重置尺寸并清空轨迹 |
| `docs/public/js/clickjs/fireworks.js` | 点击时绘制，跟踪重叠动画，全部结束后停绘；关闭效果会停止正在进行的动画 |
| `docs/public/js/birdfly.js` | 使用 `translate3d` 和按时间计算的速度移动 6 只鸟，resize 更新边界；可见且启用时仍持续飞行，不能宣称全站空闲时完全没有动画帧 |

## 吉祥物

- 主题 `layout-bottom` 只同步挂载 `StarFishMascotLoader.vue`，`window.load` 后通过 `requestIdleCallback`（4秒超时）动态导入主体及CSS，无此API时延迟1.5秒。后台取消待加载任务，卸载清理监听及调度；导入中转后台则只保留模块，回前台再挂载。
- 基础 `sprites.webp` 800×400、80,630字节（78.7 KiB），仅角色展开时低优先级加载；`wave.webp` 800×800、180,866字节（176.6 KiB），首次打招呼加载；`moods.webp` 800×800、179,668字节（175.5 KiB），首次开心/小憩加载且二者共用。基础预算100 KiB、动作图各180 KiB。手机/已隐藏首访无贴图请求；素材准备好才切换，加载期间停当前姿态，失败收回待机、按下一次意图重试。无Cubism/Pixi、模型或WebGL。
- 原生WAAPI离散background-position时间线，每步80ms，无逐帧JS循环；中途切换按currentTime取得实际帧，先倒回中立再进入最新意图。挥手3.6秒、开心2.08秒以时间线完成回待机，入睡0.64秒后保持，唤醒倒放。不要恢复happy的JS倒计时，旧实现会在暂停后重置时长且突然跳回待机。
- 「弹一下」使用基础图集第0帧，在独立 `.mascot-motion` 上以脚底 `50% 95%` 为原点做1120ms有限WAAPI变换；最大上移8%、横向放大6%，蓄力→弹起→落地→衰减回弹。复用同一animation生命周期，不引入素材、依赖或逐帧JS；弹跳期间不眨眼，中途选择只保留最后意图，落地归位后再切换，不能空中清除transform造成跳变。菜单新增按钮后按实际top计算剩余maxHeight，保留底部12px并允许内部滚动，不能只测角色边界漏掉菜单裁切。
- 手动暂停、减少动态效果、后台、拖动、阅读和打印均停时间线和待机眨眼；恢复保持进度。外层按钮/名字固定，待机无持续上下浮动；只有显式「弹一下」使用有限内层位移。阅读与打印用 `visibility:hidden` 保留时间线；显式隐藏/卸载取消动画与预载，卸载清理全部监听和观察器。阅读模式选择器整体写成 `:global(body.article-reading-mode .starfish-mascot)`，分拆global会被当前编译器截断成body选择器。
- 图集保持200px格、约178px人物高、190px脚底、100px鞋底中心，三个动作中立帧复用原待机。旧打包逐帧按整个人物alpha高度缩放，头倾/呆毛变化会传导为整身比例变化；当前两套重生成动作共用固定scale=178/306，只做裁格、邻格残片清理和鞋底定位，不再逐帧拉到相同总高。水平锚点只取人物最底部4%、alpha≥128的鞋底；旧底部12%会混入披风尖端，使入睡相邻帧鞋底中心92→110px、显示时左右乱跳。不要仅凭较大区域包围盒判定脚已对齐。仅按原图alpha包围盒缩放会混入上一行鞋底：低alpha会将残片与呆毛连通；本地打包脚本以alpha≥128的主要连通区域界定边界后去外部残片，最终须核对160px白底截图及头、胸针、脚的稳定性。
- 原画、补帧图、打包脚本、模型源及工具均在Git忽略的 `.local-assets/mascot/xiaoxingyu/`；旧补帧提示词和打包脚本保留在 `sprite-source/`；当前重生成素材、旧版备份、`generation-prompts.json`、`pack-compare.cjs`、对比图和`metrics.json`在 `regeneration-2026-10-23/`。停用Live2D的渲染器、网页资源与旧说明在 `live2d-source/archived-web-2026-10-22/`，不随站点部署。

## 首页

- `docs/index/IndexPage.vue` 保存 Typed 实例并在卸载时销毁，同时移除 resize 监听。减少动态效果时显示静态标语、关闭背景旋转与 logo 动画；背景高度测量允许 header 不存在。
- `docs/index/SponsorsLinks.vue` 的赞助及友情链接图片使用 `loading="lazy"` 和 `decoding="async"`，避免这些图片争抢首页初始加载与解码。

## 项目 Stars

- `docs/projects/ProjectPage.vue` 使用 `localStorage` 的 `stardream:github-stars:v1` 保存数量与更新时间，沿用 6 小时有效期；有效缓存直接展示，刷新或重新进入页面不请求 Stars。过期后仍立即用于卡片、总数及热门排序，同时后台刷新，不能因过期清空数字。
- 刷新成功后用有效新值覆盖缓存，部分仓库失败时保留其旧值并一同持久化；整体失败继续显示旧值且不延长缓存时间，下次访问重试。单仓库补查按仓库地址去重，不能把旧缓存当成已刷新值而跳过更新。
- 缓存及接口只接受非负安全整数（含 0），无效数量不能写成 0 覆盖旧值；损坏缓存或存储不可用时仍可请求并展示数据。无效或未来时间戳按过期处理；缓存只在客户端挂载后读取，保持 SSR 一致。

## 资源导航

- `docs/nav/NavPage.vue` 默认显示 36 个资源，通过 `IntersectionObserver` 在接近列表底部时自动追加 36 个，不移动键盘焦点或跳滚动；切换分类或搜索时重置显示数量，卸载时断开观察器。仅无该浏览器 API 时显示“加载更多”回退按钮，手动加载后聚焦第一张新增卡片。数据仍完整加载到客户端，不应宣称数据请求也按批次拆分。
- 搜索字符串在组件初始化时生成，覆盖分类、名称、简介、标签和网址并忽略大小写；输入关键词搜索全部资源。桌面侧栏与手机自绘 `SiteSelect` 共用分类状态，保留 `#分类名` 直达入口，卸载时清理 hash 监听。
- 卡片通过 `docs/nav/WebLink.vue` 接收筛选结果；不恢复每个资源的隐藏 tooltip DOM、无功能开关、深层 hover 状态或逐滚动事件测量全部分类的位置。
- 图标固定尺寸、懒加载、异步解码并提供加载失败回退；文档入口使用卡片主链接之外的独立链接。广告图片随容器等比缩放，避免固定 960px 宽度撑开手机页面。

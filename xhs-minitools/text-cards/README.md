# 文字卡片／长图

本地 Markdown 或纯文字转高清卡片。默认载入示例并实时预览，编辑、切换文字格式、主题或尺寸时自动重排。支持 3:4、1:1、长图与奶油手帐、极简白、深夜墨色三套主题，按完整文字行分页并标页码。点击生成后准备全部 2 倍清晰度图片，默认 1080×1440 像素；可清空示例或点击「试试示例」恢复。

## 文件

- `index.html` 为唯一入口。
- `styles.css` 为手机优先界面。
- `app.js` 负责设置、分页预览、逐页导出与可选 AI。
- `markdown-renderer.js` 复用原站 Markdown 子集解析和 Canvas 排版思路，增加逐行分页。
- `xhs.js` 负责平台导出、安全区与降级。

## 本地预览

在本目录运行 `python3 -m http.server 8766 --bind 127.0.0.1`，打开 `http://127.0.0.1:8766/`，或直接打开 `index.html`。页面默认显示示例的实时预览；点击「清空示例」清除当前正文，点击「试试示例」可恢复。普通浏览器的文字、主题、分页和图片预览完整可用，相册与笔记操作需在小红书中完成。

支持标题、粗斜体、删除线、行内代码、列表、引用、分隔线及围栏代码块。链接仅绘制文字，图片绘制说明，HTML 按文字处理。每次最多 30000 字符、80 页，超过时提示精简内容。长图逻辑高度上限 2048，继续分页保留后续文字。每次笔记最多 18 张，可选择分组。

AI 由 `window.xhs.AI` 提供，支持时显示入口，润色建议经用户核对后应用。未加白、配额耗尽、拦截或空结果保留原文，手动编辑始终可用。

## 校验与打包

在 `xhs-minitools` 运行 `node scripts/check.mjs`、`python3 scripts/pack.py`。README 留在源码目录。

可重复执行的回归检查另有 `node scripts/smoke.mjs`、`node scripts/image-check.mjs`、`node scripts/renderer-check.mjs`，均从 `xhs-minitools` 运行。

普通浏览器和 Mock 用于本地流程与参数验证。上传后须在创服模拟器、Android 与 iOS 真机扫码验证同一 ZIP。Chrome 61 真实内核、字体度量与真机性能仍待实测。

## 使用方法

在输入框里粘贴或输入 Markdown，右侧预览会即时渲染。选择主题（浅色或深色）和图片宽度后，点击「下载 PNG」保存到本地。

所有解析和绘制都在浏览器里用 canvas 完成，文本不会上传到任何服务器，适合处理含内部信息的笔记和代码片段。

## 支持的语法

- 标题：`#` 到 `######`，层级越大字号越小
- 段落：连续文本自动折行，中英文混排按字符和单词分别断行
- 行内样式：`**粗体**`、`*斜体*`、`~~删除线~~`、`` `行内代码` ``
- 链接：`[文字](https://example.com)`，渲染为带下划线的蓝色文字
- 列表：`-`、`*`、`+` 开头为无序列表，`1.` 开头为有序列表
- 引用：`>` 开头，左侧显示竖线
- 代码块：三个反引号包裹，等宽字体、深色或浅色底纹
- 分隔线：单独一行的 `---` 或 `***`

## 示例

输入下面这段 Markdown：

```markdown
## 今日待办

1. 修完 **接口文档** 里的示例
2. 把 `curl` 命令转成 Requests 代码

> 提交前跑一遍检查脚本。
```

选择 900 px 宽、浅色主题，导出的 PNG 就是一张 900 px 宽的图片，标题、有序列表、引用块各自保留原有层级。图片按 2 倍分辨率渲染，放大查看时文字边缘仍然清晰。

## 常见问题

**能渲染表格和图片吗？** 目前只覆盖常用的文本类语法，表格、图片、HTML 标签会按普通文本处理，不做排版。需要复杂版式时请先在其他编辑器里导出。

**长文档会怎样？** 高度上限约 16000 px，超出部分不再渲染并给出提示，建议按章节拆成多张图。

**导出的图片有页脚水印吗？** 没有，输出只有你输入的 Markdown 内容，方便直接贴到群里或文档里。

# 基础信息
GEO 即 **Generative Engine Optimization（生成式引擎优化）**：让品牌、产品或观点更容易被 ChatGPT、Claude、Gemini、Perplexity、豆包、通义等生成式 AI 发现、理解、引用和推荐。

GEO=SEO+大模型 ： 可以联网的agent本质也是调用了搜索引擎工具，当然也有一部分是训练进模型参数的知识

GEO【同行产品功能复刻】：

主流模型：ChatGPT，Claude，豆包，千问，智谱，Kimi，gemini，Grok，DeepSeek

# 系统功能
## 检测系统
检测系统【批量生成问题，自动化定时检测】

+ 提及频率变化，正负面变化
+ 文章平台【官网，猜测不同大模型会有不同的偏好：比如，元宝偏向公众号，Grok偏好X】，【偏好权威媒体、论坛、百科，社交账号还是官网】
+ 网页，云手机，API，不同地区IP
+ 品牌回答状态：被提到，被准确描述，被列入候选，被推荐为第一选择，被引用为事实来源，被错误描述或完全遗漏
+ 建立指标：被提及率，在答案中的排名，被推荐为首选的比例，不同模型中的覆盖率
+ 生成竞争对手对比报告

检测问题：【手机 电脑 空调 洗衣机】

+ 品牌词
    - 这个品牌好不好？
+ 竞品词
    - A和B哪个品牌更好，选哪个？
+ 行业词【品类推荐】【主要✨】
    - 推荐一家国内的户外品牌 / 想要买一款xxx，哪个比较好？ /  国内最好的xxx是哪个？
    - 哪家机构适合学习雅思？
+ 自动化的生文与发布系统

# 素材
### 可以设计一个简单实验：
1. 选定 100 个用户真实问题。
2. 在 ChatGPT、Perplexity、Gemini、豆包等平台分别提问。
3. 记录品牌是否出现、位置、描述和引用来源。
4. 优化官网、内容、第三方资料。
5. 一个月后重复测试。
6. 比较变化。

这会比单纯阅读大量文章更快建立理解。

## 四、研究 GEO 的实际方法论
### 关注这些可执行方向：
### 你需要关注这些可执行方向：
### 1. 官网内容优化
+ 清楚说明公司是谁、服务谁、解决什么问题
+ 产品页面写清功能、价格、适用场景和限制
+ 提供对比页、FAQ、案例、评测、数据和原始研究
+ 使用清晰标题、表格、定义和结构化内容
+ 保持公司名称、产品名称、联系方式一致

### 2. 第三方内容建设
AI 往往更信任多个独立来源，因此要研究：

+ 行业媒体报道
+ 专业评测
+ 客户案例
+ 社区讨论
+ Reddit、知乎、SegmentFault、GitHub 等平台
+ 行业目录和榜单
+ 专家访谈和引用
+ 用户评价

关键不是“制造虚假口碑”，而是让真实信息在多个可信来源中出现。

### 3. 原始数据和权威内容
容易被 AI 引用的内容通常包括：

+ 调研报告
+ 行业统计
+ 实验结果
+ 开放数据
+ 专家观点
+ 明确的定义和结论
+ 可引用的图表和案例

对于未来的 GEO 公司，这可能比批量生成普通文章更有价值。
